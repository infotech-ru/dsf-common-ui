preloadingBlockPage - Отдельный контейнер на всю страницу. Через js активировать ".preloadingBlockPage" классом "preloading__isShown"

preloadingPage - Отдельный класс на всю страницу. Через js добавлять класс "preloadingPage" например на body

preloadingBlock - Отдельный контейнер в родителе с p-relative. Через js активировать ".preloadingBlock" классом "preloading__isShown"

preloadingWrapper - Отдельный класс на весь блок. Через js передавать класс "preloadingWrapper"

preloadingInfoBlock - Отдельный контейнер в верхней правой части страницы. Через js активировать ".preloadingInfoBlock" классом "preloading__isShown"
