Всплывающие заголовки элементов формы. Скрипт formsFree

- Родителю добавляем классы js-allSelect-formFree css-formFree

- Инициализируем скрипт FormsFree();

{% highlight php %} {% highlight js %} import { FormsFree } from "../forms-free"; mounted() { FormsFree(); } {% endhighlight %}

Если нужно поднять заголовок на постоянно - добавляем к label.control-label класс модификаторcontrol-label__actvie Например так, ->label($model->getAttributeLabel('modelField'), ['class' => 'control-label control-label-actvie'])

Если нужно, чтобы плейсхолдер селекта был виден при поднятом Заголовке - добавляем в options класс selectPrompt. Обычно сочетается, когда нужен data-none-selected-text (изменяет текст-заполнитель, когда ничего не выбрано) или prompt (пункт отображается в списке по умолчанию, как обязательный выбор)

{% highlight php %} field($model, 'modelField')->widget( Select::class, [ 'options' => [ 'class' => 'form-control selectPrompt', 'multiple' => true, // 'data-none-selected-text' => Yii::t('app', 'Выбрать'), // 'prompt' => Yii::t('app', 'Все'), ], 'items' => RequestSearchForm::getmodelFieldList(), ] )->label($model->getAttributeLabel('modelField'), ['class' => 'control-label control-label-actvie']) ?> {% endhighlight %} {% highlight html %}
{% endhighlight %}
